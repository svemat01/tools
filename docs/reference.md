# Command reference

Generated by `bun run docs:generate` from the CLI's actual `--help` output. Edit command definitions to change options or descriptions; `bun run docs:check` verifies this file is current.

[Documentation home](../README.md) · [Getting started](getting-started.md)

Global options such as `--cwd` and `--verbose` go before the command: `sv --cwd ./project ready .`. A command's own options follow its name. Interactive examples and safety limits live in the workflow guides.

## sv

```text
sv 0.1.0
Inspect, prepare, review and share local files

Usage:
  sv [OPTIONS] [COMMAND]

Commands:
  ready     Preview local content preparation; apply new image outputs with undo
            history
  watch     Watch local content for read-only ready checks; never applies
            changes
  inspect   Inspect a local file or bounded directory sample without writing
  img       Image conversion, resizing, comparison and inspection
  blog      Check and prepare Markdown/MDX blog posts using a configurable
            layout
  video     Video conversion utilities
  share     Start a deliberate local sharing session; --public opts into a Quick
            Tunnel
  paste     Summarize clipboard content privately; explicitly save with --out
  history   List local file operation receipts or inspect one
  undo      Cautiously undo a recorded file operation
  doctor    Check runtime, optional tools and project configuration
  init      Preview and create a minimal sv.config.json without overwriting
  gremlins  Find suspicious or invisible Unicode characters in files and
            directories
  tunnel    Expose a local HTTP port through a Cloudflare Quick Tunnel
  jwt       Decode, sign and verify JSON Web Tokens
  dev       Development utilities

Options:
  --verbose, --no-verbose  Print debug output to stderr
  --cwd <VALUE>            Run as if started in this directory
  -h, --help               Print help
  -v, --version            Print version
```

## sv ready

```text
ready
Preview local content preparation; apply new image outputs with undo history

Usage:
  ready [OPTIONS] <PATHS>

Arguments:
  <PATHS>  Files or directories to prepare (default: current directory)

Options:
  --changed, --no-changed  Select staged, unstaged and untracked files in Git
  --apply, --no-apply      Confirm application after the full preview
  --yes, --no-yes          Authorize application without prompting
  --dry-run, --no-dry-run  Preview only, even with --apply or --yes
  --review, --no-review    Plan an offline HTML review for each applied image
  --out-dir <VALUE>        Output directory (default .sv-ready); excluded from
                           discovery
  --width <VALUE>          Maximum image width in pixels; never upscales
                           (default: 1600)
  --quality <VALUE>        Encoding quality 1-100; explicit quality reencodes
                           matching formats
  --format <VALUE>         New image output format (default: webp)
  --json, --no-json        One JSON result; application requires --yes
  -h, --help               Print help
```

  --json, --no-json                    Print machine-readable JSON
